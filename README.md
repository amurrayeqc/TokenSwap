# TokenSwap

TokenSwap is a small TypeScript command-line starter that runs a deterministic in-memory processing task and reports the result as JSON-compatible data. It is a foundation for further implementation, not a production blockchain service.

## Install

```bash
git clone https://github.com/centxyz/TokenSwap.git
cd TokenSwap
npm install
npm run build
```

## Run

```bash
npm start -- --verbose
```

## Test

```bash
npm test
```
